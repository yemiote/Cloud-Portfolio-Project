# Cloud Portfolio Project 🌐

This is a simple *static website* hosted on *Amazon S3*, demonstrating cloud deployment and secure hosting practices.

## 🚀 Project Highlights
- *Cloud Provider:* Amazon Web Services (AWS)
- *Service Used:* Amazon S3 (Simple Storage Service)
- *Hosting Type:* Static website hosting
- *Security Measures:* Configured proper S3 bucket permissions

[👉 Click to View My Portfolio](https://opeyemi-cloud-lab.s3.us-east-1.amazonaws.com/index.html)

## 🛠 Technologies Used
- AWS S3 for hosting
- HTML & CSS for web design
- IAM and bucket policies for security

## 📚 What I Learned
✔ How to deploy static websites on AWS  
✔ Best practices for S3 bucket security  
✔ How cloud storage works for web hosting
